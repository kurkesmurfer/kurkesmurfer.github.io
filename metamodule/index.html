Community ports

VCV instruments on MetaModule.

Independent ports with public source, hardware test notes, direct downloads, and visible limits.

Available now

Schlappi Engineering

Three open-source VCV modules adapted for the 4ms MetaModule and verified on hardware.

BTFLD

Bit Fold distortion, wavefolder, and four-bit asynchronous ADC. The MetaModule path uses first-order ADAA and output filtering.

Hardware tested

BTMX

Four-channel logic mixer with AND, ADD, OR, and XOR modes. The embedded path uses base-rate Schmitt logic.

Hardware tested

Nibbler

Four-bit accumulator with individual bit I/O and a stepped DAC output, using an embedded eight-times oversampled input path.

Hardware tested

Installation

Add the plugin from removable storage.

  1. Download the `.mmplugin` file.
  2. Remove any older copy of the same plugin from the `metamodule-plugins` directory on the MetaModule SD card or USB drive.
  3. Place the new file in `metamodule-plugins`, insert the media, and power on or reload plugins.
