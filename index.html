Sequencer and function generator

SpaceTime

SpaceTime is inspired by the Buchla 248 MARF. Program a shared set of stages and run up to eight independent playheads through it.

Six modules for lock-in-style patches

Homodyne

Homodyne breaks a lock-in amplifier into six VCV modules for gain, filtering, quadrature signals, demodulation, phase shifting, and polar conversion.

Explore Homodyne Source

Twenty-one-oscillator instrument

Muse

Muse is a stereo drone instrument built from 21 oscillators and 23 slow modulators. Muse-XT adds a control for keeping the chord choices closer together.

Explore Muse Source

Four-channel wavefolder

Inflection

Inflection changes its fold spacing with the movement of the incoming signal. Slow shapes stay open; faster changes fold more tightly.

Explore Inflection Source

Ninety-nine-stage stereo phaser

MultiPhaser

MultiPhaser is a stereo all-pass phaser with 99 stages, selectable tap points, CV and clock scanning, and a smaller PhaseQ voice.

Explore MultiPhaser Source
