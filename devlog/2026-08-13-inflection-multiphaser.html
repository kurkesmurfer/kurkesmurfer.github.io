13 August 2026 · Inflection + MultiPhaser

Two more instruments enter the public baseline

A test build becomes much more useful when its exact source state has a permanent name and a public history.

Inflection

Inflection is a four-channel multi-mirror wavefolder whose mirror spacing responds to signal slope. Its 2.0.0 baseline is working well in the initial Apple Silicon VCV pass, its portable DSP tests pass, and matching Intel macOS, Windows x64, and Linux x64 packages are now in the cross-platform test node.

MultiPhaser

MultiPhaser builds a stereo phase laboratory from two coherent ninety-nine-stage all-pass chains. Its family includes direct wet outputs, sixteen stereo tap slots, CV and clock scanning, a self-contained hardware companion, and the compact PhaseQ voice. Version 2.4.0 now has a clean public source baseline and a passing portable DSP suite.

The test gate

Kurkesmurfer VCV revisions are exercised first on the Apple Silicon development machine. Once that functional gate passes, matching Intel macOS, Windows, and Linux packages move to the private publishing node for native-machine acceptance. A cross-compile is evidence that the code builds; it is not a substitute for opening patches, moving controls, and listening on the target machine.

Current distinction: Inflection 2.0.0 has passed the Apple Silicon functional gate. MultiPhaser’s current public source is 2.4.0, while the externally circulated cross-platform snapshot remains 2.3.0 until 2.4.0 passes the same gate.
