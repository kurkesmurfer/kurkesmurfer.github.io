SpaceTime 2.0.0-rc.2

The new provisional VCV Rack build is available for Apple Silicon macOS, Intel macOS, Windows x64, and Linux x64.

What's in this build

  • Stage Time sets FREE or SYNC for the Program-selected stage. SYNC uses the Stage4 time slider to choose a note division from 1/64 to 4/1.
  • Head Div / Mult sets the base clock rate, and the new Head Time Mult knob continuously scales each resulting interval.
  • Program Pulse Time sets the low retrigger notch and the high pulse durations of ALL and EOC.
  • The MIDI module supports configurable Program, Stage, and contiguous Head input channels. Each Head's MIDI output lane has its own channel setting.
  • The production Head panel is now 12 HP. The 8 HP and 10 HP panels remain design references.

Platform testing

All four packages were cross-compiled with the VCV Rack Plugin Toolchain. Apple Silicon has passed a Rack smoke test. Native Rack tests on Intel macOS, Windows, and Linux remain to be completed.

The current host-side check also needs its MIDI feedback test expectations updated for the configurable channels and feedback map.

Test build: back up important patches before use. This prerelease is not a final release.
