1 August 2026 · SpaceTime

SpaceTime learns to talk back

SpaceTime’s controller layer now reports what the instrument is actually doing, rather than leaving a control surface to guess.

A larger instrument

The VCV edition now accepts as many as sixteen Stage4 blocks: 64 stages shared by up to eight independent heads. The optional Head All module provides common start, stop, advance, reset, playback-mode, clock, and normalled CV controls. Every Head also has its own reset input.

Glue modules let the chain cross empty rack space, so the larger configuration does not have to occupy one uninterrupted row.

Controller feedback

The MIDI module now has a separate controller-feedback output. A platform-neutral engine emits sparse HEAD changes, full snapshots on request, protocol discovery, and deliberately visible acknowledgement pulses for momentary Advance and Reset commands.

The first complete path covers all eight Heads and the aggregate Head All view. It has been exercised with a Korg nanoKONTROL2 through Midilize, including external LED mode, controller reconnects, panel-side edits, and mixed per-head states. Program and Stage feedback are the next implementation slice.

MetaModule

A fused SpaceTime Core is running on MetaModule hardware with all 64 stages and eight heads. Shared-memory communication, instrument IDs, persistence, MIDI clocking, manual virtual-clock pulses, and multicore behaviour have been tested. This remains development work rather than a public release: its compact user interface and complete acceptance pass still need attention.

Current status: SpaceTime remains a release candidate. The source and VCV preview builds are public; the MetaModule build is not yet presented as a supported release.
