Reading the status

Documentation freezes later than code.

A work-in-progress label means the linked information is useful and based on the current source, but names, ranges, normalizations, or platform mappings may still move before a stable release.

When the panel, tooltip, and documentation disagree, report the mismatch through the plugin’s GitHub Issues page. That discrepancy is a bug in the release baseline.
