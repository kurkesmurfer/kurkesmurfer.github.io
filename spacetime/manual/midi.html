4 HP controller and instrument gateway

MIDI

MIDI receives controller edits, clock, transport, and presets, then emits per-head notes or 7-bit CC. It is transparent to head numbering.

Placement and activity

Place MIDI directly left of Program and directly right of the heads. The green IN light reports accepted input, yellow CLK reports MIDI Clock, and red OUT reports emitted notes or CC.

Device and channels

Head All controlsProgram channel CC 32–44 broadcasts Head CC 0–12 to every Head.
Clock and transportMIDI System Realtime; channel-independent.
Head output lanesEach Head's output channel is independently selectable from 1–16.
Controller feedbackSeparate MIDI output; replies follow the configured Program, Stage, and Head channels.

By default, channels 1–8 carry Head controls, channel 15 carries Stage sliders, and channel 16 carries Program commands. Channels 9–14 are free. Program may share a channel with one of its Heads because their CC ranges differ. The Stage channel cannot overlap Program or any active Head. The Head-start setting is limited so the active range never wraps past channel 16.

The MIDI module context menu sets the Program channel, Stage channel, contiguous Head channel start, and each Head's output lane. The HEAD N output submenu selects its mode, channel, note gate source, and CC number. The Rack MIDI input is forced to All channels. The panel readout shows the Program, Head-start, and Stage channels.

Realtime clock and transport

F8 supplies MIDI Clock to heads whose clock source is MIDI. FA Start, FB Continue, and FC Stop affect only heads with Follow MIDI transport enabled.

The current implementation advances from individual F8 edges through the Head Div/Mult setting. A separate musical 24 PPQN interpretation layer is not part of version 2.0.0.

Controller feedback

Select a separate feedback output in the MIDI module context menu. It is Off by default. Snapshot requests use the configured Program channel: CC 50 requests a Head (value 0–7) or all Heads (8); CC 51 requests Program; CC 52 requests a Stage page (0–7); and CC 53 probes the protocol version. Replies use the configured Head, Stage, and Program channels. CC 117 returns the development version byte; CC 118/119 frame explicit snapshots. Program state uses feedback CC 94–113, and stage slider values use CC 0–127 on the configured Stage channel.

Per-head output

Configure each of eight lanes from the MIDI module's HEAD N output submenu.

ModeBehavior
OffNo output; any active note is released.
NotesQuantized Head CV becomes MIDI note number with 0 V = note 60. Gate source is Pulse 1, Pulse 2, or All.
CC 7-bitHead CV becomes the selected CC, send-on-change with a short throttle.

Pulse 1/2 notes end on gate fall. All produces a fixed 30 ms note. Unquantized stages do not emit notes.

Deferred MIDI features

14-bit CC, NRPN, note input, MIDI learn, and MIDI-clock output are intentionally outside the 2.0.0 scope.
