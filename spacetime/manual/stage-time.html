Stage Time

Stage Time sets the timing interpretation of the stage selected in Program. It follows that selection, so the mode can be programmed one stage at a time without adding controls to the Head.

FREE and SYNC

ModeMeaning
FREEThe Stage4 time slider and its selected range set the stage interval as usual.
SYNCThe same slider selects one of nine note divisions, from 1/64 through 4/1. Stage4 displays the selected division and note symbol above the slider.

Move the spring-return switch up to set FREE or down to set SYNC. The upper and lower red LEDs show the stored mode; the switch itself returns to center.

How the Head interprets SYNC

The Head playing the stage supplies the clock source. With External, MIDI, or Virtual clock, the Head's Div / Mult setting selects the base clock rate and the stage division scales it. With an Internal clock, the current slider value supplies the free-time base and the selected division scales that interval. The Head's Time Mult control scales the resulting interval further.

Stage duration does not stretch the stage-address range: each address still selects one stage.

Selection and instrument ID

The number display follows Program's selected stage. When placed beside Program, Stage Time follows that Program's instrument ID automatically. Its bottom selector can change the ID when used standalone or when routing among multiple SpaceTime instances.

Apply to all stages

Stage Time mode edits use Program's normal all-stage edit behavior. Arm Apply next edit to ALL stages in Program, then set FREE or SYNC once to apply that mode to every stage.
