VCV Rack 2 instrument family

SpaceTime

One programmable field of stages. Up to eight independent ways through it.

Architecture

An instrument assembled to fit the patch.

SpaceTime deconstructs the programming surface and function generators of the Buchla 248 concept into a contiguous VCV family. Stage blocks own their data, heads share the field without sharing transport, and MIDI sits transparently between them.

Head All (optional)→Head ×1–8→MIDI→Program→Stage4 ×1–16

Preview builds

Install SpaceTime manually.

Download the `.vcvplugin` package for Apple Silicon macOS, Intel macOS, Windows x64, or Linux x64 from GitHub Releases.

  1. In Rack, choose Help > Open user folder, then quit Rack.
  2. Place the package in the matching plugins-<OS>-<CPU> directory. Do not unpack it.
  3. Restart Rack and find the modules under Kurkesmurfer.
